GreenThumb is an IoT-powered smart plant care platform that allows users to monitor and manage household plants in real-time. 
By combining sensor-enabled hardware with a cross-platform mobile app, 
GreenThumb simplifies plant irrigation and health tracking for users with busy lifestyles.

---

## Features

-  **Real-time Sensor Monitoring** – Soil moisture, light, and water tank levels via ESP32 and Firebase.
- **Smart Irrigation Control** – Automate watering based on moisture levels or manually control it through the app.
- **Moisture History Visualization** – Interactive line charts showing historical data trends.
- **Firebase Integration** – User authentication and cloud storage for garden data.
- 🛠**User-Friendly Interface** – Built using React Native with responsive UI and tooltips.

---

## Tech Stack

| Layer            | Technology Used                       |
|------------------|----------------------------------------|
| Hardware         | ESP32 microcontroller + sensors        |
| Communication    | MQTT (Mosquitto Broker)                |
| Backend          | Firebase Firestore + Firebase Auth     |
| Frontend         | React Native (Android-focused)         |
| Data Visualization | Chart.js & react-native-svg          |
